# Lille Lasse Örns märkvärdiga äventyr

Персональная интерактивная книга на шведском языке для Виктора: девять акварельных сцен, книжный разворот, небольшие находки, сертификат личности и поздравление.

## Запуск

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm run lint
npm run typecheck
npm run test:e2e
npm run build
npm run preview
```

Для браузерных тестов нужен Chromium Playwright (`npx playwright install chromium`). Сайт работает без сервера приложений, аналитики, учётных записей и внешних запросов при чтении. Vite создаёт статический каталог `dist`.

## Редактирование подарка

- `src/data/story.ts` — текст истории, альтернативные описания и интерактивные подсказки.
- `src/data/book.ts` — главы и список разделов, автоматически задающий оглавление и счётчики.
- `src/data/chapterTeaser.ts` — заключительный анонс второй главы.
- `src/data/birthday.ts` — короткое поздравление и подпись.
- `src/data/personalBirthday.ts` — личное письмо, заключительное поздравление, подпись и P.S.
- `src/app/Book.module.scss` — оформление книги.
- `src/utils/certificate.ts` — клиентская генерация PDF.
- `docs/illustrations.md` — художественный манифест и промпты.

Все изображения и шрифт хранятся локально. Семейный фотографический референс не включён в `public` и не распространяется вместе с сайтом. Сходство акварельного персонажа — художественная интерпретация фотографии, а не точная фотокопия.

Оригинальные реплики и декоративные подробности вымышлены; семейные факты сохранены. Музыкальная находка — визуальный эффект, без записи или текста песен Evert Taube.

## Архитектура

`App` управляет текущей сценой; `BookReader` отвечает за навигацию и переходы. Обложка, страницы, интерактивные детали, сертификат и поздравление выделены в отдельные компоненты. Глобальное хранилище не требуется. PDF-библиотека загружается только при скачивании. Изображения имеют размеры, версии WebP для двух разрешений и локальное состояние ошибки. Анимации учитывают reduced motion.

Шрифт Lora распространяется под SIL Open Font License; лицензия находится в `public/fonts/OFL.txt`.

## Будущие главы

Чтобы добавить завершённую главу, создайте её сцены с существующим типом `StoryScene` и добавьте объект `StoryChapter` в `chapters` в `src/data/book.ts`. Название главы, её сцены, иллюстрации и интерактивные элементы появятся в существующем читателе; оглавление, последовательность и число разделов рассчитываются автоматически. Анонс второй главы не содержит пустых сцен и не регистрируется как доступная глава. Сейчас книга содержит 13 разделов, завершающихся анонсом после личного письма.
