# Проверка шведской версии книги

Проверено локально 13 октября 2026 года.

## Автоматические проверки

- `npm run lint` — успешно.
- `npm run typecheck` — успешно, строгий TypeScript.
- `npm run format:check` — успешно.
- `npm run build` — успешно; статический каталог `dist`.
- `npm run test:e2e` — 10 успешно пройденных тестов: 5 сценариев в desktop Chromium и 5 в мобильной эмуляции Chromium.

Проверены шведский язык документа, девять сцен, оглавление из 13 разделов, четыре интерактивные находки, обе реакции выбора, скачивание `Lasse-Orn-Identitetsintyg.pdf`, печатная версия сертификата, короткое поздравление, отдельное личное письмо, переход назад и повторное чтение. Проверены стрелки клавиатуры, Escape, фокус заголовка и reduced motion.

Во всех девяти сценах, на обложке и в личном письме проверено отсутствие горизонтального переполнения на ширинах 320, 390, 768 и 1440 px. Все иллюстрации успешно декодируются. Автоматический axe-аудит обложки, первой сцены, сертификата и личного письма по WCAG A/AA не обнаружил нарушений. В основном сценарии не зарегистрированы ошибки JavaScript или сообщения console.error.

Отдельно проверена production-сборка через `vite preview` на мобильной ширине 390 px: HTTP 200, язык `sv`, скачивание шведского PDF, переход через короткое поздравление к личному письму, индикаторы 12 / 13 и 13 / 13 и повторное чтение. Ошибок JavaScript и console.error нет.

## Визуальная проверка

Просмотрены локальные скриншоты шведской обложки, сертификата и длинного личного письма на мобильном экране. Скачанный клиентский PDF растеризован и просмотрен: å, ä, ö отображаются корректно, текст сертификата не обрезан, орнамент присутствует.

## Границы проверки

Мобильные проверки выполнены в эмуляции Chromium. Реальные устройства, Safari/Firefox, физический принтер и вспомогательные технологии вручную не проверялись. Автоматический axe-аудит не заменяет полную ручную проверку доступности. История использует окончательный перевод пользователя, личное письмо хранится отдельно; короткое поздравление переведено дополнительно.

## Публикация

Изменения выполнены только локально. Исходники и личное письмо в Sites не отправлялись; публикация не выполнялась.

## Анонс второй главы

После личного письма добавлен самостоятельный анонс с точным шведским текстом. Проверены переход из письма к анонсу и обратно, открытие из оглавления, закрытие книги, повторное чтение, фокус заголовка, обычная анимация и reduced motion, декодирование новой акварели и отсутствие переполнения на 320, 390, 768 и 1440 px. axe-аудит анонса не обнаружил нарушений. Исходные тексты первой главы, поздравлений и сертификата сохранены. Скриншоты анонса просмотрены в desktop и mobile.

Финальная production-сборка также проверена через `vite preview`: HTTP 200, PDF-сертификат скачивается, личное письмо ведёт на анонс с индикатором 13 / 13, новая акварель декодируется, кнопка повторного чтения возвращает на обложку. Ошибок JavaScript и console.error нет.
